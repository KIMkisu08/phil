유튜브 다운로더 사용법 (Windows 노트북 + 아이폰)

[처음 한 번만]
1. YouTubeDownloader.exe를 원하는 곳(예: 바탕화면)에 두고 더블클릭
   - "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]
     (개인이 만든 서명 없는 프로그램이라 뜨는 경고입니다)
2. "필수 프로그램 설치" 창이 뜨면 [예]
   → FFmpeg(변환)와 Deno(유튜브 해석)가 자동 설치됩니다 (검은 창이 잠시 열림)
3. Firefox를 설치하고 YouTube Premium 계정으로 youtube.com에 로그인
   (Chrome/Edge는 보안 정책 때문에 로그인 정보 읽기가 자주 실패합니다)

[사용]
1. YouTubeDownloader.exe 실행 (처음 켜질 때 몇 초 걸립니다)
2. 링크 붙여넣기 → [불러오기]
3. "음원: Premium 고음질 · opus 256kbps" 로 표시되는지 확인
   ("일반 음질"로 나오면 Firefox 로그인 상태 확인)
4. 형식 선택
   - 음원 (아티스트 + 곡 제목 입력)
     · 아이폰용 AAC 256kbps (.m4a) : 기본값. 아이폰 음악 앱용
     · MP3 320kbps                 : 차량/기타 기기용
     · CD 굽기용 FLAC              : CD 전용 (아이폰 음악 앱 재생 불가)
   - 영상 (제목만 입력)
     · 아이폰 호환 화질이 기본 선택됨 (보통 1080p)
     · 주황색 경고가 뜨는 화질은 노트북 감상용 (아이폰 재생 안 될 수 있음)
5. [다운로드]
6. 저장 이름
   - 음원: "아티스트 - 곡제목.m4a" + 아티스트/제목 태그 + 앨범아트
   - 영상: "제목.mp4" + 제목 태그

[아이폰으로 옮기기]
파일을 그냥 복사하면 음악 앱에 안 나옵니다. 동기화가 필요합니다.
1. Microsoft Store에서 "Apple 기기(Apple Devices)" 앱 설치 (구형 Windows 10에서 안 되면 iTunes)
2. 앱의 음악 보관함에 받은 .m4a/.mp3 파일 추가
3. 아이폰을 케이블로 연결 → 음악 동기화
   (아티스트/제목/앨범아트가 음악 앱에 그대로 표시됩니다)
영상: 같은 앱의 동영상 동기화, 또는 파일 앱으로 옮겨서 재생

[CD 만들기]
CD 굽기용 FLAC 파일들을 CDBurnerXP(무료) → "오디오 디스크"에 넣고 굽기.
최대 약 80분(700MB CD 기준).

[다운로드가 갑자기 안 될 때]
화면 아래 [다운로드 엔진(yt-dlp) 업데이트] 클릭 → 프로그램 다시 실행.
창 제목의 "엔진 날짜"가 바뀌면 적용된 것입니다.
(업데이트 파일 위치: %LOCALAPPDATA%\YouTubeDownloader\lib — 문제가 생기면 이 폴더를 지우면 원래대로)

※ 개인 소장용으로만 사용하고 재배포하지 마세요.
